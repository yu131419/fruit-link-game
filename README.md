## ✨ 游戏简介

> 一款轻量、无广告、直接可玩的网页游戏。  
> 打开即玩，操作流畅，适合休闲放松。  
> 支持在 **手机浏览器、微信、Telegram** 中无障碍运行。

---

## 🧩 游戏特色

| 特性 | 说明 |
|------|------|
| 🍉 **多种水果图标** | 随机生成关卡，保持新鲜感 |
| 🍋 **触屏优化** | 手机端点击顺滑、响应迅速 |
| 🍇 **关卡与计分系统** | 记录你的最高分数与连击 |
| 🍎 **可扩展性强** | 支持自定义水果图片与难度 |
| 🍒 **离线可玩** | 打包后可直接在本地运行 |
